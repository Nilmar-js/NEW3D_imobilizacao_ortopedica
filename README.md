# New3D Landing Page

Landing page institucional da New3D, criada em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` - página principal
- `css/style.css` - estilos e responsividade
- `js/script.js` - menu mobile
- `assets/ortese-antebraco-punho.webp` - imagem enviada
- `assets/infografico-new3d.jpg` - infográfico enviado

## Como usar

Abra `index.html` no navegador.

Para publicar no GitHub Pages, envie a estrutura inteira para o repositório e mantenha `index.html` na raiz.

## Personalização

Existem blocos "ESPAÇO PARA IMAGEM" no catálogo. Eles foram deixados de propósito para receber futuras imagens de órteses de falanges, dedos, punho, polegar e outros modelos.

Também substitua:
- `contato@new3d.com.br` pelo e-mail real da empresa.
- Links/contatos reais quando definidos.

## Observação

O texto institucional foi estruturado para apresentar o conceito do produto sem substituir avaliação, indicação ou acompanhamento de profissional habilitado.
