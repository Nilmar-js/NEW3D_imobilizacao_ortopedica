# New3D Landing Page

Landing page institucional da New3D, criada em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` - página principal
- `css/style.css` - estilos e responsividade
- `js/script.js` - menu mobile
- `assets/ortese-antebraco-punho.webp` - imagem enviada
- `assets/infografico-new3d.jpg` - infográfico enviado
